# Employee Attrition Analysis using Power BI

## Project Overview
This project analyzes employee attrition patterns using Microsoft Power BI. The dashboard helps identify key factors associated with employee turnover and provides insights to support employee retention strategies.

## Key Metrics
- Total Employees: 1,000
- Attrition Rate: 19.7%
- Employees Left: 197

## Key Analysis
The dashboard analyzes employee attrition based on:
- Department
- Job Role
- Overtime
- Job Satisfaction
- Years at Company
- Work-Life Balance
- Job Involvement
- Distance from Home

## Key Insights
- Research & Development and Sales show higher numbers of employee attrition.
- Overtime is an important factor associated with employee turnover.
- Job satisfaction levels show differences in employee attrition.
- Work-life balance and job involvement are also analyzed as potential factors.
- Certain job roles show comparatively higher attrition.

## Recommendations
- Reduce excessive overtime and improve workload distribution.
- Improve employee job satisfaction through regular feedback.
- Promote better work-life balance and flexible work practices.
- Focus retention efforts on high-attrition job roles.
- Monitor employee attrition regularly using data-driven analysis.

## Tools Used
- Microsoft Power BI
- Microsoft Excel
- DAX

## Project Outcome
An interactive Power BI dashboard was created to visualize employee attrition patterns and provide actionable recommendations for improving employee retention.
